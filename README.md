# Profile Card Website

A responsive personal profile card built using HTML and CSS. This project showcases my profile, technical skills, project statistics, and social media links in a clean and modern design.

## Features

- Responsive profile card layout
- Profile image with a cover banner
- Custom Nunito font
- Technology skill badges
- Profile statistics section
- Social media links and icons
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Font Awesome
- Custom Fonts

## Project Structure

```text
profile-card/
├── index.html
├── styles.css
├── images/
├── fonts/
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
